\textbf{Sprint 1:} 2--15 Nov 2026 \quad \textbf{Review:} 16--24 Nov 2026 \quad \textbf{Features:} F1, F2, F3, F4 \quad \textbf{Planned: 84 points (proposed)}

\textbf{Sprint goal:} A verified IBA member can sign up, build a profile, find the right person, connect and chat, and post or answer a need.

The sprint backlog breaks every Sprint 1 item into tasks. Each item is built on its own \texttt{feature/*} branch and merged into \texttt{develop} by pull request when it meets the Definition of Done. \textbf{Owner} and \textbf{Status} are filled in from the Trello board as work happens; points are proposals until the team confirms them.

\textbf{Order:} foundation first, then F1 $\rightarrow$ F2 $\rightarrow$ F3 $\rightarrow$ F4, with the dashboard and account deletion last because they depend on F3 and F4.

\section*{Foundation (no story points)}
Repository restructure, test tooling and CI, UI foundation and app shell, database schema and seed, API foundation (errors, validation, access guard, rate limiter, email), documentation scaffold.
